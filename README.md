# ML Engineering Lab

This repository contains practical machine learning engineering work focused on model training, evaluation, deployment, and production-style AI workflows.

## Focus Areas

- Data preparation and feature engineering
- Regression and classification
- Model evaluation
- Tree-based models and ensemble methods
- FastAPI model serving
- Dockerized inference services
- Serverless and container-based deployment concepts
- Production-style AI workflow automation

I am a software engineering graduate with backend experience building automation workflows, data-processing features, and AI-assisted systems. This repository is focused on strengthening my practical machine learning engineering skills.
